# Terminal

## O que é
Um terminal e uma interface gráfica de texto cada comando digitado diz ao computador oque ele deve fazer

## Comandos úteis
```bash

pwd Mostra a pasta atual

ls Exibe o couteudo da pasta

ls -l Exibe o coutedo da pasta em detalhes

cd Para mudar de pasta

cd .. Para voltar uma pasta

find Para localizar um arquivo

cat Para ler arquivos

whoami Mostra nome de usuario atual

uname -a Ele mostra a linha completa de informações do sistema

df -h Ele mostra o tamanho do disco de uma forma que possa entender
