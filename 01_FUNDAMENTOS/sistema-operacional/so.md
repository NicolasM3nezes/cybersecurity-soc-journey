# Sistema Operacional

## Como funciona
 Um sistema operacional ele fica entre o Hardware e os aplicativos tipo o Hardware são as peça física o sistema operacional ele controla as peças e organiza tudo

 ## Segurança
 Como um sistema fica entre o hardware e os aplicativos, eles devem ser sempre protegidos por que ninguem quer, que você envie uma foto para uma pessoa e outras pessoas conseguem ver, então temos que proteger três coisas

 ### Confidencialidade
 É necessário para que apenas pessoas com autorização tenha acesso

 ### Integridade
 É crucial para que não seja modificado nenhum tipo de arquivo durante o transporte na rede

 ### Disponibilidade
 Para que possa ser usado quando quiser,
