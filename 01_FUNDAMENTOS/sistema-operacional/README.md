# Sistema Operacional

## O que é um sistema operacional?

Um **sistema operacional** é o software principal que fica entre o **hardware** e os **aplicativos**.

O **hardware** são as partes físicas do computador, como:

- Processador
- Memória RAM
- HD/SSD
- Teclado
- Mouse
- Placa de rede
- Monitor

O sistema operacional é responsável por controlar essas peças, organizar os recursos do computador e permitir que os aplicativos funcionem corretamente.

Exemplos de sistemas operacionais:

- Windows
- Linux
- macOS
- Android
- iOS

---

## Segurança em sistemas operacionais

Como o sistema operacional fica entre o hardware e os aplicativos, ele precisa ser protegido.

Se um sistema não estiver seguro, informações importantes podem ser acessadas, modificadas ou até mesmo apagadas por pessoas não autorizadas.

Na segurança da informação, existem três pilares principais que precisam ser protegidos:

- **Confidencialidade**
- **Integridade**
- **Disponibilidade**

Esse conjunto também é conhecido como **Tríade CIA**.

---

## Confidencialidade

A **confidencialidade** garante que apenas pessoas autorizadas tenham acesso às informações.

Exemplo:

Se você envia uma foto ou documento para uma pessoa específica, outras pessoas não devem conseguir visualizar esse conteúdo sem permissão.

A confidencialidade ajuda a proteger dados como:

- Senhas
- Documentos pessoais
- Fotos
- Informações bancárias
- Dados de empresas

---

## Integridade

A **integridade** garante que as informações não sejam alteradas de forma indevida.

Isso significa que um arquivo, mensagem ou dado deve permanecer correto e confiável durante o armazenamento ou transporte pela rede.

Exemplo:

Se você envia um arquivo para alguém, ele deve chegar exatamente como foi enviado, sem alterações não autorizadas.

A integridade ajuda a evitar:

- Modificação indevida de arquivos
- Alteração de informações importantes
- Corrupção de dados
- Manipulação de mensagens

---

## Disponibilidade

A **disponibilidade** garante que sistemas, arquivos e serviços estejam acessíveis quando necessário.

Exemplo:

Um site, sistema ou arquivo importante precisa estar disponível para uso sempre que o usuário precisar.

A disponibilidade pode ser afetada por:

- Ataques
- Falhas no sistema
- Problemas de rede
- Erros de configuração
- Falta de manutenção

---

## Exemplo de ameaça: Ransomware

O **ransomware** é um tipo de software malicioso que pode comprometer a segurança de um sistema operacional.

Ele geralmente funciona criptografando os arquivos da vítima, impedindo o acesso aos dados originais. Para recuperar o acesso, o atacante exige um pagamento, conhecido como resgate.

Um ataque de ransomware pode afetar os três pilares da segurança:

### Confidencialidade

Os dados podem ser acessados ou roubados por pessoas não autorizadas.

### Integridade

Os arquivos podem ser modificados ou criptografados, deixando de estar em seu estado original.

### Disponibilidade

O usuário perde o acesso aos arquivos ou sistemas, pois os dados ficam bloqueados.

---

## Conclusão

A segurança de um sistema operacional é essencial para proteger dados, usuários e serviços.

Entender conceitos como **confidencialidade**, **integridade** e **disponibilidade** ajuda a compreender melhor como ataques funcionam e como podemos proteger os sistemas contra ameaças.

Esse conhecimento é uma base importante para quem está estudando **Segurança da Informação**, **Cybersecurity**, **SOC** e **Blue Team**.
