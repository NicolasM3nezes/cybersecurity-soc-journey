# Prompt de Comando

## Como funciona
Prompt de comando (CMD) Ele é uma interface grafica de texto para interagir com windows com comandos para navegar entre pastar, executar comandos de redes entre outras coisa

## Comandos úteis
```bash

cd Mostra a pasta atual e para mudar de pasta

dir Exibe o couteudo da pasta

dir /a  Exibe o coutedo oculto da pasta em detalhes

cd .. Para voltar uma pasta

dir /s Para localizar um arquivo

type Para ler arquivos

whoami Mostra nome de usuario atual

systeminfo Ele mostra a lista completa de informações do sistema

hostname Mostra qual e o nome do computador

ipconfig Mostra informações basica de redes
