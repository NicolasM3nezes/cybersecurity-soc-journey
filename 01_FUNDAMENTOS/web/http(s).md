# HTTP(S)

## O que é HTTP
O HTTP ele é usado sempre que acessa um site, ele é um conjunto de regras usado para comunicação de servidores web

## O que é HTTPS
O HTTPS é a versão segura do HTTP criando uma criptografia

### Oque é URL
URL são  instruções para acessar algum recurso na internet

Schema: Este documento indica qual protocolo usar entre HTTP, HTTPS e FTP.

User: São para fazer autenticações em algum serviço 

Port: Seria qual vai ser porta que vai se conectar

Path: O caminho do arquivo ou localização para acessar

Query String: é uma referência na página local

### Métodos HTTP

Solicitação GET: Usado para pegar informaçõesdo servidor

Solicitação POST: Usado para enviar dados ao servidor ou criar novos registros

Solicitação PUT: Usado para atualizar informações no servidor

Solicitação DELETE: Usado para apagar informações do servidor

### Codigos de Status HTTP

100 à 199: São respostas de informações

200 à 299: São respostas de sucesso.

300 à 399: São respostas de redirecionamento

400 à 499: São respostas de erro na parte do cliente

500 à 599: São respostas de erro na parte do servidor

### Cabeçalho de requisição comum

Host: Ele informa site deve acessar

User-Agent: Qual navegador esta fazendo a requisição

Set-Cookie: O servidor envia os cookie para o computador

Cache-control: Ele define por quanto tempo deve guardar  o coutendo em cache

Content-Type: Informa qual couteudo esta sendo enviado
