# DHCP

## O que é
Servidor DHCP ele atribui IP automaticamente aos dispositivos

## Oque eu entendi sobre
Todos endereço IP pode ser atribuido manualmente ou automaticamente que é no caso do servidor DHCP, quando uma pessoa se conecta à uma rede, DHCP Discover fazer uma busca para saber se o dispositivo ja tem um IP, caso ele não tenha ele fazer um DHCP Offer ele oferece um IP para o dispositivo, caso o dispositivo aceite vai fazer um DHCP Request, onde vai falar para o servidor, olha eu aceito esse IP pode me mandar, Então o DHCP ACK fazer o envio do IP e manda uma mensagem de IP atribuido com sucesso!
