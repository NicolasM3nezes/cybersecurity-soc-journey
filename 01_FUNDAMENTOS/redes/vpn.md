# VPN 

## O que é
VPN Virtual private network ele cria um tunel seguro

# Tipos de VPN

## PPP
Point-to-Point protocol esse tipo de VPN ele permite uma comunicação entre dois pontos e fazer autênticações

## PPTP
Point-to-Point Tenneling Protocol ele cria um tunel para transporta o PPP

## IPsec
Internet Protocol Security esse tipo ele protege comunicação usando criptografia aplicado na camada de rede
