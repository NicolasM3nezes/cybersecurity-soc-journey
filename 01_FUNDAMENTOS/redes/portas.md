# PORTAS

## O que é
Portas e onde você quer acessar, tipo ip é endereço de uma casa, mas você não sabe qual a porta entrar.

## 21 - FTP
Porta de transferência de arquivos

## 22 - SSH
Porta para acesso remoto

## 53 - DNS
Porta para consultas e resposta de sites

## 80 - HTTP
Porta de sites sem criptografia

## 443 - HTTPS
Porta de sites com criptografia

## 445 - SMB
Porta de compartilhamento de pastas e arquivos

## 3389 - RDP
Porta para acesso a interface gráfica de outro dispositivo
