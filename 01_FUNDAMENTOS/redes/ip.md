# IP

## O que é
IP ou melhor Protocolo de internet são como nossos nome em uma rede podendo ser alterado

## Oque eu entendi sobre
O IP ele pode ser usado para buscar maquinas em uma rede mais facilmente, sendo o IPv4 ou IPv6, hoje temos dois tipos de IP sendo o Público e o Privado, IP privado ele é usado para conversar com maquinas em uma area local como um escritorio por exemplo, o IP público ele é necessario para que as maquina naveguem pela internet.
