# ARP 

## O que é
O ARP ele associa o endereço IP ao Endereço MAC

## Oque eu entendi sobre
O ARP tem um cache onde ele guarda todo mapeamento, o ARP ele faz uma solicitação envia uma mensagem perguntando Preciso do MAC, quem tem esse IP dentro da rede, então apenas o 
IP correspondente, responde eu tenho esse IP, esse é o meu MAC, Então ele salva esses dados no cache
